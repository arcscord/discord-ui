# Discord interfaces, composed with React

Arcscord Discord UI renders Discord-style interfaces from your application's data.
Use it for documentation, message builders, interactive previews and transcripts.

<DiscordUI theme="dark" locale="en-US" timeZone="UTC" referenceTime="2026-11-01T10:24:00Z">
  <Message message={{ id: 'intro', author: { id: 'bot', displayName: 'Welcome Bot', bot: true }, timestamp: '2026-11-01T10:24:00Z', body: { kind: 'markdown', content: '**Hello from React.** Try this spoiler: ||You found it!||' } }} />
</DiscordUI>

## What you can build

- Individual messages with Markdown, mentions, emoji, replies, embeds and files.
- Components V2 layouts with buttons, select menus, galleries and containers.
- Channels with message history, a composer, slash commands and thread navigation.
- Light, Ash and Dark previews with custom tokens and translated interface labels.

The [component catalogue](/components?example=message) shows real package components.
The [playground](/playground?example=message) lets you edit complete React examples.
Channel sends and thread replies in these examples are local browser simulations.

## What your application owns

Supply resolved authors, entities, string IDs and explicit timestamps. Handle
interaction callbacks, update the displayed data, and own persistence and network
requests. Rendering a message does not send it to Discord. Display models are not
Discord send payloads or a validator for those payloads. An ephemeral flag describes
appearance; your application controls access to private data.
