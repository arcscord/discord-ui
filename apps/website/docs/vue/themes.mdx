# Themes and localization in Vue

Bind `:theme` on `DiscordUI` to `light`, `ash` or `dark`. Use
`defineTheme` from `@arcscord/discord-ui-vue/themes` to inherit a preset and
override semantic tokens. Bind `:tokens` for overrides specific to one
preview. Each `DiscordUI` provides display options to its descendants.

Bind `:locale` and `:time-zone` for timestamp formatting. Pass `:labels`
to translate interface text, including accessible labels such as
`closeThread` and `showSpoiler`. A partial label object inherits defaults
for the other keys.

Supply explicit timestamps with a time-zone offset or UTC. For relative
times, pass a stable `reference-time`. Use the same values for the initial
server and client renders. Check keyboard operation and visible focus
when adding slot content or overriding theme tokens.
