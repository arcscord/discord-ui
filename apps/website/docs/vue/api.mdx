# Vue API reference

Generated from the built public Vue declarations. Each component below corresponds
to the React component of the same name and uses the shared display models.
Import components and types from `@arcscord/discord-ui-vue`. Models are re-exported
from the core; their constraints are unchanged.

Content props become named slots; events use kebab-case. Listener signatures appear
below as Vue's typed `on…` props. `class` and `style` are native Vue attributes.

## Themes and highlighting

`./themes` re-exports the core presets, token types, `defineTheme`,
`resolveTheme` and `themeStyle`. `./highlight` exports
`renderHighlightedCode(content, language)`, returning Vue nodes for
`DiscordUI.renderCode`. Unknown languages fall back to escaped plain text.
Highlighting grammars do not enter the ordinary component bundle.
