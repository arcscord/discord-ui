Complete the [installation](./installation.md) first. Then copy this

## Understand the data

| Field | Meaning |
| --- | --- |
| `id` | Stable string identifying this message |
| `author` | Resolved display data supplied by your application |
| `timestamp` | Explicit ISO 8601 instant including a time zone |
| `body.kind` | Selects text, Markdown or a Components V2 body |
| `body.content` | Markdown source for this example |

`MessageView` checks the display model while authoring TypeScript. It does not
validate data at runtime or convert it into a Discord API payload. Use
`body: { kind: "text", content: "Hello from React!" }` when formatting is unwanted.

## Understand the wrapper

`DiscordUI` scopes styles and shares display options. Set `theme` to `light`,
`ash` or `dark`. `locale` and `timeZone` control formatting; the explicit
`referenceTime` gives relative timestamp rendering a stable reference. Keep these
values identical on the server and client when hydrating.

The spoiler uses local UI state. Buttons, selections, reactions and sends can
report interaction intent through callbacks; your application handles updates
and persistence. This example makes no Discord requests.
