## MessageComponents

<CodeBlock language="ts">{"import { MessageComponents } from \"@arcscord/discord-ui\";"}</CodeBlock>

Renders a serializable component tree. Standalone callers supply messageId when callback context needs it. Select keys scope controlled values; omitted keys use menu-local state. No Discord payload validation or network call occurs.

[Usage guide](/docs/guides/components-v2) · [Props type](#messagecomponentsprops)

<CodeBlock language="ts">{"export function MessageComponents({ components, referenceTime, messageId, selectValues, onButtonClick, onSelectChange, onPremiumClick }: MessageComponentsProps): import(\"react\").JSX.Element;"}</CodeBlock>

### Props

Optional props without a listed default remain absent; the behavior note describes local-state and wrapper fallbacks. Callback arguments are included in their type.

| Field | Required | Type | Default / fallback | Meaning |
| --- | --- | --- | --- | --- |
| `onButtonClick` | No | `((id: string, context: ComponentInteractionContext) => void) \| undefined` | — | Called with (componentId, context); host handles the requested action. |
| `onSelectChange` | No | `((id: string, values: string[], context: ComponentInteractionContext) => void) \| undefined` | — | Called with (selectId, proposedValues, context); host updates any controlled values. |
| `onPremiumClick` | No | `((skuId: string, context: ComponentInteractionContext) => void) \| undefined` | — | Called with (skuId, context); no purchase or product lookup is performed. |
| `components` | Yes | `readonly MessageComponent[]` | — | Ordered component nodes; the owning union determines which variants are allowed. |
| `referenceTime` | No | `string \| undefined` | — | Stable ISO reference for relative timestamps. Renderer-specific fallback is explained above. |
| `messageId` | No | `string \| undefined` | — | Originating message ID or original-message reference as indicated by the type. |
| `selectValues` | No | `Readonly<Record<string, readonly string[] \| undefined>> \| undefined` | — | Values by select ID. Missing keys/undefined use local state; [] controls an empty selection. |

## Button

<CodeBlock language="ts">{"import { Button } from \"@arcscord/discord-ui\";"}</CodeBlock>

A native action button. onClick reports intent with no arguments; message-rendered buttons adapt this to an ID and message context. Premium style is visual only. Disabled prevents activation.

| Field | Required | Type | Default / fallback | Meaning |
| --- | --- | --- | --- | --- |
| `label` | Yes | `string` | — | Visible control/choice text; supply a meaningful accessible name. |
| `ariaLabel` | No | `string \| undefined` | — | Accessible name override. Emoji-only model buttons fall back to the emoji name; supply this for custom primitive React slots. |
| `style` | No | `"primary" \| "secondary" \| "success" \| "danger" \| "premium" \| undefined` | `"primary"` | Button visual variant; premium is appearance, not a billing integration. |

## SelectMenu

<CodeBlock language="ts">{"import { SelectMenu } from \"@arcscord/discord-ui\";"}</CodeBlock>

A five-variant select over a complete resolved snapshot. Omit values for local defaults; pass [] to control an empty selection. Defaults do not overwrite existing local state. New ID/kind resets local state. Unavailable/duplicate values are removed from the effective selection and maximum limits apply; entity menus search locally.

[Usage guide](/docs/guides/interactions) · [Props type](#selectmenuprops)

<CodeBlock language="ts">{"export function SelectMenu(props: SelectMenuProps): import(\"react\").JSX.Element;"}</CodeBlock>

### Props

Optional props without a listed default remain absent; the behavior note describes local-state and wrapper fallbacks. Callback arguments are included in their type.

| Field | Required | Type | Default / fallback | Meaning |
| --- | --- | --- | --- | --- |
| `menu` | Yes | `SelectMenuView` | — | One of the five discriminated menu models; include all currently selected entities. |
| `values` | No | `readonly string[] \| undefined` | `Local menu defaults` | Controlled standalone values; omission uses local defaults. Duplicate/unavailable values are filtered. |
| `onChange` | No | `((values: string[]) => void) \| undefined` | — | Proposed standalone selection values; update controlled values to accept. |
