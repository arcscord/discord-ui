## ChannelComposer

<CodeBlock language="ts">{"import { ChannelComposer } from \"@arcscord/discord-ui\";"}</CodeBlock>

Controlled plain-text draft plus local slash-command/argument editing. onSend reports text without clearing a standalone draft; the host clears value. onSlashCommand receives a supplied command and nonblank arguments, then local command state clears. Required/choice validation gates local invocation. Enter sends and Shift+Enter inserts a line; IME composition is respected.

## ChannelView

<CodeBlock language="ts">{"import { ChannelView } from \"@arcscord/discord-ui\";"}</CodeBlock>

Displays header, ordered history, built-in composer and loaded linked threads. Data is application-owned. Sends report content; the built-in local draft clears after a handled send. Channel identity resets local state. A changed last message ID scrolls to the bottom when autoScroll is enabled. Omitted activeThreadId enables local navigation; string/null makes it controlled.

[Usage guide](/docs/guides/channels) · [Props type](#channelviewprops)
