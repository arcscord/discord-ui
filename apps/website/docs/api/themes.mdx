# Theme helpers and tokens

Signatures and field tables are extracted from the public TypeScript contracts. Behavior notes and examples are maintained alongside the generator. Model optionality does not imply a runtime default. Field tables scroll horizontally at narrow widths.

[Public entry points](/docs/api/entry-points) · [API index](/docs/api-reference)

## defineTheme

<CodeBlock language="ts">{"import { defineTheme } from \"@arcscord/discord-ui\";"}</CodeBlock>

Creates an immutable custom theme description. name is required; extends defaults to dark; tokens defaults to an empty override map; colorScheme inherits unless explicit. Parent tokens merge without mutating the parent. The preset base remains available to compiled CSS.

<CodeBlock language="ts">{"export function defineTheme({ name, extends: parent, tokens, colorScheme }: { name: string; extends?: ThemeInput; tokens?: ThemeOverrides; colorScheme?: \"light\" | \"dark\"; }): DiscordTheme;"}</CodeBlock>

### Example

<CodeBlock language="ts">{"import { defineTheme } from \"@arcscord/discord-ui\";\n\nconst preview = defineTheme({ name: \"violet\", extends: \"ash\", tokens: { accent: \"#a7a9ff\" } });"}</CodeBlock>

[Theme guide and rendered example](/docs/guides/themes)

Related types: [DiscordTheme](/docs/api/themes#discordtheme).

## themes

<CodeBlock language="ts">{"import { themes } from \"@arcscord/discord-ui\";"}</CodeBlock>

Readonly preset descriptions: light uses colorScheme=light; ash and dark use colorScheme=dark. Preset token maps are empty because their palette is supplied by compiled CSS.

<CodeBlock language="ts">{"export const themes: { readonly light: { readonly name: \"light\"; readonly base: \"light\"; readonly colorScheme: \"light\"; readonly tokens: {}; }; readonly ash: { readonly name: \"ash\"; readonly base: \"ash\"; readonly colorScheme: \"dark\"; readonly tokens: {}; }; readonly dark: { readonly name: \"dark\"; readonly base: \"dark\"; readonly colorScheme: \"dark\"; readonly tokens: {}; }; };"}</CodeBlock>

### Example

<CodeBlock language="ts">{"import { themes } from \"@arcscord/discord-ui\";\n\nconst preview = themes.light;"}</CodeBlock>

## DiscordTheme

<CodeBlock language="ts">{"import type { DiscordTheme } from \"@arcscord/discord-ui\";"}</CodeBlock>

Reusable theme description with name, retained CSS base, light/dark color scheme and readonly partial token overrides. Supply it to DiscordUI.theme.

<CodeBlock language="ts">{"type DiscordTheme = {\n  readonly name: string;\n  readonly base: string;\n  readonly colorScheme: \"light\" | \"dark\";\n  readonly tokens: Readonly<ThemeOverrides>;\n};"}</CodeBlock>

| Field | Required | Type | Default / fallback | Meaning |
| --- | --- | --- | --- | --- |
| `name` | Yes | `string` | — | Resolved display name, command/argument name or file name as indicated by the owning type. |
| `base` | Yes | `string` | — | Underlying CSS preset name retained through theme inheritance. |
| `colorScheme` | Yes | `"light" \| "dark"` | — | Light/dark browser color scheme; inherited unless overridden. |
| `tokens` | Yes | `Readonly<Partial<ThemeTokens>>` | — | Semantic token overrides applied over the selected/inherited theme. |

### Example

<CodeBlock language="ts">{"import type { DiscordTheme } from \"@arcscord/discord-ui\";\n\nconst preview: DiscordTheme = { name: \"violet\", base: \"ash\", colorScheme: \"dark\", tokens: { accent: \"#a7a9ff\" } };"}</CodeBlock>

## themeStyle

<CodeBlock language="ts">{"import { themeStyle } from \"@arcscord/discord-ui/themes\";"}</CodeBlock>

Available from /themes only. Converts supplied semantic token keys to their CSS custom-property names in a React CSSProperties object. It does not validate contrast or apply a stylesheet.

<CodeBlock language="ts">{"export function themeStyle(tokens: Readonly<ThemeOverrides>): CSSProperties;"}</CodeBlock>

### Example

<CodeBlock language="ts">{"import { themeStyle } from \"@arcscord/discord-ui/themes\";\n\nconst style = themeStyle({ accent: \"#5865f2\" });"}</CodeBlock>

[Theme guide and rendered example](/docs/guides/themes)

## resolveTheme

<CodeBlock language="ts">{"import { resolveTheme } from \"@arcscord/discord-ui/themes\";"}</CodeBlock>

Available from /themes only. Resolves a preset name/custom object and merges per-scope overrides (default `{}`). Returns a new theme object; it does not register global state.

<CodeBlock language="ts">{"export function resolveTheme(theme: ThemeInput, overrides?: ThemeOverrides): DiscordTheme;"}</CodeBlock>

### Example

<CodeBlock language="ts">{"import { resolveTheme } from \"@arcscord/discord-ui/themes\";\n\nconst preview = resolveTheme(\"ash\", { accent: \"#5865f2\" });"}</CodeBlock>
