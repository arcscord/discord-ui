## UnicodeEmojiOptions

<CodeBlock language="ts">{"import type { UnicodeEmojiOptions } from \"@arcscord/discord-ui\";"}</CodeBlock>

Native Unicode by default, or Twemoji SVGs from an explicit baseUrl. Local root-relative sources work with allowRemoteMedia=false. HTTP(S) sources require remote media permission. Failed images preserve Unicode; no CDN is implicit.

<CodeBlock language="ts">{"export type UnicodeEmojiOptions = { mode: \"native\" } | { mode: \"twemoji\"; baseUrl: string };"}</CodeBlock>

#### Variant 1

| Field | Required | Type | Default / fallback | Meaning |
| --- | --- | --- | --- | --- |
| `mode` | Yes | `"native"` | — | Unicode emoji rendering mode: native text or explicitly sourced Twemoji SVGs. |

#### Variant 2

| Field | Required | Type | Default / fallback | Meaning |
| --- | --- | --- | --- | --- |
| `mode` | Yes | `"twemoji"` | — | Unicode emoji rendering mode: native text or explicitly sourced Twemoji SVGs. |
| `baseUrl` | Yes | `string` | — | Root-relative directory or explicit HTTP(S) URL containing codepoint.svg files, subject to the shared media policy. |

### Valid examples

<CodeBlock language="ts">{"export type ChannelViewModel = {\n  id: string;\n  name: string;\n  topic?: string;\n  messages: readonly MessageView[];\n  threads?: readonly ThreadView[];\n};"}</CodeBlock>

| Field | Required | Type | Default / fallback | Meaning |
| --- | --- | --- | --- | --- |

| --- | --- | --- | --- | --- |

| `minValues` | No | `number` | — | Minimum user-removal limit, bounded to 0–effective maximum; does not invent missing selections. |
