## renderHighlightedCode

<CodeBlock language="ts">{"import { renderHighlightedCode } from \"@arcscord/discord-ui/highlight\";"}</CodeBlock>

Opt-in renderer returning a code React element from (content, language). Language is lowercased. Registered languages are javascript, typescript, json, css, bash and python; unsupported languages return escaped plain code. It does not sanitize arbitrary custom renderer output.
