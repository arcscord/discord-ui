## DiscordUI

<CodeBlock language="ts">{"import { DiscordUI } from \"@arcscord/discord-ui\";"}</CodeBlock>

Scopes compiled CSS and provides theme, entities, labels, date formatting and media policy. Partial labels merge with English defaults; tokens override the selected theme. Configuration does not fetch entities or authorize access. The wrapper owns no message data.

[Usage guide](/docs/guides/themes) · [Props type](#discorduiprops)

<CodeBlock language="ts">{"export function DiscordUI({ children, className, ...options }: DiscordUIProps): import(\"react\").JSX.Element;"}</CodeBlock>

### Props

Optional props without a listed default remain absent; the behavior note describes local-state and wrapper fallbacks. Callback arguments are included in their type.

| Field | Required | Type | Default / fallback | Meaning |
| --- | --- | --- | --- | --- |
| `theme` | No | `ThemeInput` | `"dark"` | Preset name or custom theme object; does not replace the stylesheet import. |
| `tokens` | No | `Partial<ThemeTokens>` | `{}` | Semantic token overrides applied over the selected/inherited theme. |
| `locale` | No | `string` | `"en-US"` | Intl locale for dates, numbers and thread plural selection; does not translate labels. |
| `timeZone` | No | `string` | `"UTC"` | Explicit Intl time zone for date/time formatting and date separators. |
| `referenceTime` | No | `string` | — | Stable ISO reference for relative timestamps. Renderer-specific fallback is explained above. |
| `entities` | No | `MessageEntities` | `{}` | Resolved lookup maps or resolved menu entities, as specified by the owning model. No network lookup. |
| `allowRemoteMedia` | No | `boolean` | `true` | Allows HTTP(S) image sources. false preserves accepted local/blob/data images and does not disable outgoing links. |
| `unicodeEmoji` | No | `UnicodeEmojiOptions` | — | Native Unicode by default; twemoji requires an explicit baseUrl serving codepoint SVG files. Local paths work with remote media disabled; failed images fall back to Unicode. |
| `renderCode` | No | `((content: string, language: string) => ReactNode) \| undefined` | — | Optional code renderer receiving (content, language). Return React content; opt-in highlighter has a separate entry. |
| `labels` | No | `Partial<UILabels>` | `English defaults (partial merge)` | Interface-label configuration; DiscordUI accepts partial overrides merged with English defaults. |
| `children` | Yes | `ReactNode` | — | Explicit React content/slots; not part of a serializable display snapshot. |
| `className` | No | `string` | `""` | Additional class on the scope wrapper. |

## Message

<CodeBlock language="ts">{"import { Message } from \"@arcscord/discord-ui\";"}</CodeBlock>

Renders a complete classic or Components V2 snapshot, with optional reply, edits, reactions, ephemeral notice and thread summary. Callbacks report intent; the host updates the model. Ephemeral is appearance, not authorization. Body Markdown/V2 and embeds use the wrapper reference time or message timestamp.

[Usage guide](/docs/guides/messages) · [Props type](#messageprops)
