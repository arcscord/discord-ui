# Searching the documentation

Open **Search docs** in the navigation or [the search page](/search). On narrow
screens the link is in the navigation menu. Type a component, prop or task name;
all query words must match the same document section. Exact section titles rank
above mentions in prose.

Try [SelectMenu](/search?q=SelectMenu), [controlled selections](/search?q=controlled%20selections)
or [thread replies](/search?q=thread%20replies). Results link to guide, API, recipe
and project sections. Camel-case API names and words are searchable. Up to 30
results are shown; refine the query when it is broad.

Results update while typing. Press Search or Enter to save the current query in
the URL for sharing/reloading. Use Tab to reach result links and Enter to open one.
Empty queries show suggestions; unmatched queries show a no-results message.

## Scope and privacy

The index is generated from the public documentation included in this build and
loaded with the search page. Queries are processed in the browser without an
external search service. Draft/unlisted documents are excluded. This does not
turn public site content into private data or index unpublished repository files.

Search is lexical, not semantic: try a documented English component/property name
or fewer words when no result appears. Message content and source edits in the
playground are not dynamically added to the documentation index.
