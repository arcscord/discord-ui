# Svelte

The native Svelte adapter uses the shared Discord display models and runs on
Svelte 5.46.4 or later in the Svelte 5 line. Its components are compiled by the
consumer's Svelte tooling.

## Installation

For the local release candidate, run `pnpm build:lib` at the repository root.
Pack both libraries with `pnpm --filter @arcscord/discord-ui-core pack` and
`pnpm --filter @arcscord/discord-ui-svelte pack`. In a Svelte app, install the
Svelte archive and add a pnpm override pointing `@arcscord/discord-ui-core`
to the matching Core archive. See the [package README](https://github.com/arcscord/discord-ui/tree/main/packages/discord-ui-svelte)
for the exact commands.

Import `@arcscord/discord-ui-svelte/styles.css` once and use `DiscordUI` to
scope styles and provide display options. Each example below uses public
package imports. Copy its Svelte file into your app to edit the data and
interactions.

## Markdown, embeds and media

Models contain serializable display data with string IDs and explicit timestamps.
The host supplies authors, mentions and other entities. To convert received API
data, import `fromDiscordMessage` or `fromDiscordMessageComponents` from
`@arcscord/discord-ui-core/discord-api` with Core installed directly.

This example uses the optional `HighlightedCode` component in a `renderCode`
snippet. Serve the [demo image](/examples/landscape.svg) at the same path in your
app or substitute your own image URL.

## Components V2 and interactions

Use native snippets to compose primitives. For model-driven layout, pass a
Components V2 body to `Message`. Typed callbacks report IDs and message context
so the host can update its data. The `selectValues` map controls selections by
component ID. A missing entry uses local state and `[]` controls an empty
selection. For a channel or thread, use `selectValuesByMessage` to scope the map
to each message.

## Channels, slash commands and threads

The example accepts local messages and replies and reports slash commands through
`onSlashCommand`. The composer can also be used independently with `value` and
`onValueChange`. Omit `activeThreadId` for local navigation or pass `null`
to close the controlled thread.

## Themes and media policy

Choose Light, Ash or Dark as the base for your preview, then override semantic
tokens with `defineTheme`. The provider also accepts labels, a locale, a time zone
and a media policy. This example uses the default that allows remote media.
With `allowRemoteMedia={false}`, same-site paths and entries
that match `remoteMediaAllowlist` remain eligible. Image loading failures show
the fallback.
